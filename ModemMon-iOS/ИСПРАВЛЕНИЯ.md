# Исправления бэндов и инструментов

- Навигация использует NavigationPath и поддерживает переходы не только по строкам, но и по типам SysRoute и UciRoute.
- Парсер ModemManager читает только секцию Bands и сохраняет многострочные supported/current, не смешивая их с Modes и Hardware.
- Для ModemManager команда выбора — `--set-current-bands`, значения разделяются `|` и передаются как один аргумент. Если выбор пуст, передаётся полный список поддерживаемых бэндов.
- Ошибки чтения и выполнения команды отображаются; после применения показания читаются снова. В демо-режиме выбор работает локально и не управляет модемом.

## Проверка

На Mac с Xcode 16+ откройте `ModemMon.xcodeproj`, соберите приложение и проверьте переходы в каждом пункте «Система → Инструменты», а также «Конфиг UCI». В демо-режиме проверьте выбор/применение бэндов. Затем на реальном роутере сравните список с выводом `mmcli -m any`, попробуйте разрешить небольшой поддерживаемый набор и восстановить все диапазоны. Применение может временно прервать связь; проводите проверку при доступе к роутеру другим способом.

Из папки проекта на Mac можно выполнить независимые тесты парсера:

```sh
swiftc ModemMon/BandsCodec.swift Tests/main.swift -o /tmp/modemmon-bands-tests
/tmp/modemmon-bands-tests
```

Команды старого CGI `op=status`/`op=bands_set` были предположены в исходном проекте. Их необходимо проверить на вашей прошивке; если контракт отличается, потребуется его описание или пример ответов CGI. Бинарная сборка и проверка на роутере в этой среде не выполнялись.
